# Muhammad Hassan Ali Shah — Personal Portfolio (`HassanPortfolio`)

A responsive, enterprise-grade personal portfolio website built for **Muhammad Hassan Ali Shah** (Software Engineer | .NET | Enterprise Application Development).

## 1. Tech Stack & Architecture
- **Markup:** Semantic HTML5 with ARIA attributes, Open Graph metadata, and keyboard accessibility.
- **Styling:** Custom CSS3 (`assets/css/style.css`) paired with official **Bootstrap 5.3.3** and **Bootstrap Icons 1.11.3** via CDN.
- **Interactivity:** Vanilla JavaScript (`assets/js/main.js`) for project category filtering, mobile navigation management, and a `mailto:` email composer.
- **Zero Backend Lock-in:** Runs natively in any browser or static hosting environment without Node.js or database dependencies.
